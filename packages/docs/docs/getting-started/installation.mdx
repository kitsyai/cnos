# Installation

Global CLI:

```bash
npm install -g @kitsy/cnos-cli
cnos --version
```

Runtime in an app:

```bash
npm install @kitsy/cnos
```

Vite:

```bash
npm install @kitsy/cnos @kitsy/cnos-vite
```

Next.js:

```bash
npm install @kitsy/cnos @kitsy/cnos-next
```
