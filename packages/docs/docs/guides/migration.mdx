# Migrating from .env

Use the migration assistant:

```bash
cnos migrate --scan src --dry-run
cnos migrate --apply
cnos migrate --apply --rewrite
```

Bridge to existing tooling:

```bash
cnos export env --to .env.local
cnos export env --profile stage --to .env.stage
```
