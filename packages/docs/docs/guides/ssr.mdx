# SSR Projects

Use `@kitsy/cnos` on the server and `@kitsy/cnos/browser` only for promoted public values.

Typical split:

- server: `cnos.value(...)`, `cnos.secret(...)`
- browser: `cnos('public.some.key')`
- framework build: `@kitsy/cnos-vite` or `@kitsy/cnos-next`
